# Repository Copilot Task Prompts

Use one prompt at a time from the target repository. Each change must be reviewed before merge.

## Shared Prompt Requirements

Every prompt below instructs Copilot to:

- Modify only the named repository.
- Create a branch and PR; do not merge automatically.
- Improve README quality and add one allowed status label.
- Add a privacy and safety note.
- Soften unsupported production claims while preserving useful technical content.
- Make the repository understandable to LinkedIn visitors.
- Avoid exposing secrets, patient data, hospital internal data, corporate contact data, pricing, proposal details, WhatsApp exports, OP numbers, or credentials.
- Use only verified technologies, commands, and claims.
